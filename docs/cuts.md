# 两个版本 · 2'45" / 1'50"

同一批镜头、同一条像素曲线、同一段五音主题，只换剪点。

- **长版 2'45"（165 秒）**：9 站全留，交给课程完整放映。
- **短版 1'50"（110 秒）**：删掉站 2「QQ 时代」与站 6「代码层」，其余各站收紧，用于时长受限的场合或作为预告。

两版都从同一份 `src/constants.ts` 的 `STATION_PLAN` 推导，改秒数就等于改剪法，场景代码不用重写。

## 短版删了什么，为什么

**删站 2「QQ 时代」**：它是全片最依赖文化记忆的一站，笑点来自火星文和窗口抖动。没经历过那个年代的人接不住，而节奏上它只是「又一次被界面甩出去」，与站 1、站 3 的功能重复。

**删站 6「代码层」**：它的作用是让观众看见「规则」——`fix()` 被改成 `escape()`。但站 7 已经用子像素阵列把「它其实和大家一样」讲明白了，短版让信息流直接撕裂到硬件，逻辑仍然成立，而且更狠。

**没有删站 7、站 8**：这两站是全片的论点。短版可以少铺垫，不能少结论。

## 两版共用的东西

| 共用项 | 说明 |
|---|---|
| 像素曲线 | 一条连续的绝对帧曲线，剪点变了只改帧号，不改走位逻辑 |
| 五音主题 | 一段旋律 9 种音色；短版少两次变奏，BPM 与调性不变 |
| 转场语法 | 统一「钻进去」的推镜；短版把信息流→硬件改成同一次撕裂 |
| 视觉规则 | 每站画风都变，只有它是同一个红色方块 |

## 对音乐的约束

两版都要成立，所以主题必须写成「可循环的 8 小节」，而不是一条跟着画面走的线性配乐：

- 每站至少完整落一遍主题，长版靠变奏撑时长，短版靠剪站省时间；
- 转场点必须落在小节线上，短版的删站才不会听着像跳针；
- 结尾的钢琴弦乐版两版完全一致——那是全片唯一一次「真实乐器」，不能剪。
